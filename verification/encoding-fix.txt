ПРОВЕРКА ИСПРАВЛЕНИЯ КОДИРОВКИ

Исходный дефект воспроизведён: 87/92 теста при обычном запуске Python
в Windows без PYTHONIOENCODING и PYTHONUTF8. Пять проверок русской
диагностики вычислений получали сообщения Windows-1251, хотя сценарий
тестирования декодировал их как UTF-8.

Исправление: сгенерированная программа настраивает stdout и stderr
на UTF-8 до импорта NumPy. Сценарий тестирования также задаёт UTF-8
для собственного вывода и строго проверяет кодировку дочерних процессов.
Проверки ошибок и их содержания сохранены.

Добавлена отдельная проверка runtime_error_utf8_with_cp1251_environment:
сгенерированная программа запускается с PYTHONIOENCODING=cp1251
и PYTHONUTF8=0. Сообщение о вырожденной матрице должно быть корректным
UTF-8, содержать причину и положение в исходнике, без traceback.

Результаты после исправления:
Windows x64: 93/93, test-report.json.
Windows PowerShell 5.1, без специальных переменных среды: 93/93,
windows-powershell-test-report.json и windows-powershell-tests.log.
Linux x86_64 в WSL: 93/93, linux-test-report.json.

Обе готовые сборки пересобраны из исправленных исходников.
Примеры Python сгенерированы заново.
