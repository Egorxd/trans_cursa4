# Matrix Translator 1.0.0

Matrix Translator переводит программы на языке матричных вычислений в Python. Транслятор проверяет исходный текст, типы и размеры матриц. Численные результаты появляются при запуске созданного файла с NumPy.

## Быстрый запуск в Windows

Распакуйте архив и откройте PowerShell в папке проекта. Для выполнения примера нужен Python 3.11 или новее x64 с командой `python` в PATH. Скрипт установки создаёт окружение `.venv` и устанавливает NumPy из `requirements.txt`. При первой установке нужен доступ к интернету.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\bin\translator.exe examples/input.txt -o demo_output.py
.\.venv\Scripts\python.exe demo_output.py
```

Первой командой подготовьте окружение, второй создайте `demo_output.py`, третьей выведите результаты. Для показа примера с подписями к операциям можно открыть `run_example.bat`.

## Работа с программой

- [Справка пользователя](USER_GUIDE.md) содержит команды запуска для Windows и Linux, правила входного языка и разбор ошибок.
- [Сборка из исходников](BUILD.md) описывает установку инструментов, сборку с Flex и Bison, запуск тестов и работу через Docker.
- [Готовый пример](examples/input.txt) показывает все матричные операции. Свои программы можно писать в любом редакторе, который сохраняет UTF-8.

## Проверка

После установки NumPy запустите тесты из папки проекта.

```powershell
.\.venv\Scripts\python.exe tests/run_tests.py
```

При успешном запуске последняя строка будет `93/93 passed`.

## Файлы проекта

Для сборки используйте `src/` с кодом на C и заголовком, `grammar/` с правилами Flex и Bison и `generated/` с готовыми исходниками анализаторов. Команды сборки находятся в `build.ps1`, `Makefile` и `Dockerfile`. Набор проверок находится в `tests/`.

Для запуска используйте `bin/translator.exe` в Windows x64 или `bin/translator` в Linux x86_64. Для полученных программ установите зависимости из `requirements.txt` по справке. В `examples/` лежат входной файл, полученный код и дампы вывода. В `verification/` лежат журналы тестов, в `docs/` находится исходное техническое задание.
