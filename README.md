# Matrix Translator 1.0.0

Транслятор переводит язык матричных вычислений из файлов `.mat` в Python. До записи результата он проверяет синтаксис, объявления, типы и размеры матриц. Сгенерированная программа выполняет вычисления с помощью NumPy.

## Быстрый запуск в Windows

Откройте PowerShell в этой папке. Готовый `bin/translator.exe` работает в Windows 10 и 11 x64 без установки компилятора, Flex, Bison или сторонних DLL.

```powershell
.\bin\translator.exe examples/input.mat -o examples/output.py
.\.venv\Scripts\python.exe examples/output.py
```

Локальное окружение `.venv` подготовлено на этом компьютере. При переносе работы на другой компьютер его нужно создать заново. Установите Python 3.11 или новее и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_example.ps1
```

Можно также открыть `run_example.bat`: при отсутствии окружения он запускает установку NumPy и выполняет пример. Демонстрация показывает исходные матрицы и подписи перед каждым результатом; числа отображаются с округлением до 10 значащих цифр. Установка зависимостей впервые требует доступа к интернету. Окружение `.venv` не входит в архив сдачи.

## Материалы для сдачи

| Путь | Содержимое |
| --- | --- |
| `grammar/parser.y`, `grammar/lexer.l` | Исходная грамматика Bison и правила лексического анализа Flex |
| `src/` | Исходные файлы программы на C и заголовок |
| `generated/` | Сгенерированные файлы C и H для сборки без Flex и Bison |
| `bin/translator.exe` | Готовый транслятор для Windows x64 |
| `bin/translator` | Статически собранный транслятор для Linux x86_64 |
| `BUILD.txt`, `build.ps1`, `Makefile` | Инструкция и команды сборки |
| `Dockerfile` | Контейнер со сборкой из грамматики, тестами и Python с NumPy |
| `docs/Справка_пользователя.md`, `.txt`, `.html` | Справка пользователя в трёх форматах |
| `docs/Пояснительная_записка.md`, `.html` | Описание языка, грамматики, архитектуры и генерации кода |
| `docs/Техническое_задание.docx` | Копия исходного задания |
| `tests/` | Позитивные и негативные программы, ожидаемые результаты и автоматический запуск |
| `examples/` | Входной пример, результат трансляции и дампы стандартных потоков |
| `verification/` | Протоколы выполненных проверок и сведения о сборке |

Справка и пояснительная записка в HTML открываются в браузере и пригодны для печати. Для сборки с нуля и запуска Docker следуйте `BUILD.txt`.

## Проверка

```powershell
.\.venv\Scripts\python.exe tests/run_tests.py --report verification/test-report.json
```

Тесты проверяют результаты с относительной погрешностью `1e-9` и абсолютной `1e-10`, а также коды завершения, позиции ошибок, отсутствие выходного файла при ошибках и сохранение существующего файла. Текущий результат проверки указан в `verification/Проверка.txt`.
