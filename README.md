# Matrix Translator 1.0.0

Транслятор переводит язык матричных вычислений из файлов `.txt` в Python. До записи результата он проверяет синтаксис, объявления, типы и размеры матриц. Сгенерированная программа выполняет вычисления с помощью NumPy.

## Быстрый запуск в Windows

Готовый `bin/translator.exe` работает в Windows 10 и 11 x64 без установки компилятора, Flex, Bison или сторонних DLL. Для выполнения полученных программ нужен Python 3.11 или новее x64 с добавлением команды `python` в PATH.

Распакуйте весь архив в отдельную папку. Откройте `run_example.bat`: он создаст окружение `.venv`, установит NumPy и выполнит демонстрацию с подписями результатов. Для первой установки зависимостей требуется интернет.

Для запуска через PowerShell выполните в папке проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\bin\translator.exe examples/input.txt -o examples/output.py
.\.venv\Scripts\python.exe examples/output.py
```

В демонстрации числа отображаются с округлением до 10 значащих цифр. При прямом запуске Python-файла выводятся обычные значения Python и NumPy. Окружение `.venv` создаётся на компьютере получателя и не входит в архив.

## Материалы для сдачи

| Путь | Содержимое |
| --- | --- |
| `grammar/parser.y`, `grammar/lexer.l` | Исходная грамматика Bison и правила лексического анализа Flex |
| `src/` | Исходные файлы программы на C и заголовок |
| `generated/` | Сгенерированные файлы C и H для сборки без Flex и Bison |
| `bin/translator.exe` | Готовый транслятор для Windows x64 |
| `bin/translator` | Статически собранный транслятор для Linux x86_64 |
| `BUILD.txt`, `build.ps1`, `Makefile` | Инструкция и команды сборки |
| `Dockerfile` | Контейнер со сборкой из грамматики, тестами и Python с NumPy |
| `docs/Справка_пользователя.md`, `.html` | Справка пользователя в исходном и печатном форматах |
| `docs/Пояснительная_записка.md`, `.html` | Описание языка, грамматики, архитектуры и генерации кода |
| `docs/Техническое_задание.docx` | Копия исходного задания |
| `tests/` | Позитивные и негативные программы, ожидаемые результаты и автоматический запуск |
| `examples/` | Входной пример, результат трансляции и дампы стандартных потоков |
| `verification/tests.log`, `verification/tests-linux.log` | Результаты 93 автоматических проверок в Windows и Linux |

Для сборки с нуля и запуска Docker следуйте `BUILD.txt`.

## Проверка

```powershell
.\.venv\Scripts\python.exe tests/run_tests.py
```

Ожидаемый итог — `93/93 passed`. Тесты проверяют результаты с относительной погрешностью `1e-9` и абсолютной `1e-10`, а также коды завершения, позиции ошибок, отсутствие выходного файла при ошибках и сохранение существующего файла. Журналы выполненных проверок находятся в `verification/tests.log` и `verification/tests-linux.log`.
