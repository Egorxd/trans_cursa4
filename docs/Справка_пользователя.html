К комплекту работы

Справка пользователя Matrix Translator

Версия 1.0.0

Matrix Translator преобразует записи матричных вычислений в программу Python. Вы задаёте матрицы, выражения и команды вывода в текстовом файле. Транслятор проверяет этот файл и создаёт программу, которую можно запустить для получения результатов. Сами вычисления происходят при запуске программы Python.

Установка и первый запуск

В Windows 10 или 11 x64 используйте bin/translator.exe. Дополнительные библиотеки для этого файла устанавливать не требуется. Для выполнения созданных программ установите Python 3.11 или новее x64. Рекомендуются версии 3.12 и 3.13.

Откройте PowerShell в папке проекта и выполните установку NumPy в отдельное окружение:

powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1

Затем выполните пример:

.\bin\translator.exe examples/input.mat -o examples/output.py
.\.venv\Scripts\python.exe examples/output.py

Можно открыть run_example.bat, который выполнит эти действия для примера и покажет пояснения перед каждым результатом. В демонстрации числа отображаются с округлением до 10 значащих цифр. Прямой запуск файла examples/output.py выводит значения без подписей. Если окружение уже подготовлено, доступ к интернету для запуска не нужен. При переносе папки на другой компьютер повторите установку окружения.

В Linux x86_64 используйте bin/translator. Сделайте файл исполняемым командой chmod +x bin/translator. Порядок установки Python и NumPy, сборки из исходников и запуска в Docker описан в BUILD.txt.

Формат запуска

translator input.mat -o output.py
translator --help
translator --version

input.mat — существующий файл с исходным текстом. output.py — файл, который будет создан после успешной проверки. Ключ -o обязателен. В Windows команда обычно начинается с .\bin\translator.exe, в Linux — с ./bin/translator. Путь с пробелами заключайте в двойные кавычки.

Входной и выходной файлы должны быть разными, в том числе не должны быть жёсткими ссылками на один файл. При успешной трансляции существующий выходной файл заменяется. При ошибке исходной программы новый выходной файл не создаётся, а существующий сохраняется. Папка для выходного файла должна существовать и быть доступна для записи.

При некорректном запуске показывается краткая справка. Транслятор возвращает код 0 при успехе, 1 при ошибке исходной программы, 2 при неправильном формате команды и 3 при ошибке файлов, памяти или превышении размера входного файла. Сообщение об успехе идёт в стандартный вывод, сообщения об ошибках — в стандартный поток ошибок.

Формат исходного файла

Язык разработан для этой работы и не является реализацией внешнего стандарта. Файл должен быть обычным текстом UTF-8; отметка BOM разрешена только в начале файла. Допустимы окончания строк LF и CRLF. Расширение .mat рекомендуется, но не проверяется. Пустой файл и файл только из комментариев допустимы и создают программу без вывода.

Каждая команда заканчивается точкой с запятой ;. Пробелы, табуляция и переносы строк разделяют слова; их количество несущественно. В одной строке может быть несколько команд. Команды исполняются сверху вниз.

Имена переменных состоят из латинских букв, цифр и знака _, причём первый символ должен быть буквой или _. Регистр учитывается: A и a — разные имена. Кириллица в именах не поддерживается. Имена matrix, number, print, transpose, det, rank, inverse зарезервированы. Имена, совпадающие с другими словами Python, например class, допустимы.

Числа

Поддерживаются десятичные целые и вещественные литералы, знак + или -, а также экспоненциальная запись:

0   12   -3   +4   2.5   .5   1.   -2.5e-3   3E+2

Десятичный разделитель — точка. Запятая служит разделителем элементов и аргументов. Записи NaN, Inf, шестнадцатеричные числа, числа с _ и комплексные числа не поддерживаются. Начальные нули допустимы и не означают восьмеричную запись.

Числа и элементы матриц обрабатываются с точностью float64: примерно 15–16 значащих десятичных цифр. Слишком большие литералы и ненулевые литералы, которые округляются до нуля, отклоняются. Пример предельной ошибки: 1e309. Арифметика с вещественными числами может давать небольшие ошибки округления.

Объявления и присваивания

matrix A = [[1, 2], [3, 4]];
number n = 2.5;
A = transpose(A);
n = n + 1;

matrix объявляет матрицу, number — число. Начальное значение обязательно. Переменная доступна после своего объявления. Повторно объявить то же имя нельзя. Присваивать новое значение объявленной переменной можно многократно, но её тип остаётся прежним. Матрица при присваивании может изменить размеры; последующие операции проверяются с учётом нового размера.

Не допускаются number n;, matrix A = 5;, number n = [[1]]; и обращение к переменной до её объявления. Инициализация number n = n + 1; также недопустима, если n объявляется впервые.

Запись матрицы

Матрица записывается как список строк в квадратных скобках. Каждая строка — отдельный список чисел:

matrix A = [[1, -2, 3.5], [4, 5, 6]];
matrix B = [[7]];

У матрицы должна быть хотя бы одна строка и хотя бы один элемент в каждой строке. Все строки должны содержать одинаковое количество элементов. Внутри литерала разрешены только числовые литералы с необязательным одиночным знаком. Имена переменных, функции, выражения и дополнительные уровни вложенности в качестве элементов запрещены. Запятая после последнего элемента или строки запрещена.

Недопустимые примеры: [], [[]], [[1, 2], [3]], [1, 2], [[n]], [[1+2]], [[[1]]].

Выражения и операции

ЗаписьЗначениеУсловия
A + BПоэлементное сложение матрицОдинаковые размеры
A - BПоэлементное вычитание матрицОдинаковые размеры
A * BМатричное умножениеСтолбцов у A столько же, сколько строк у B
a + b, a - b, a * bАрифметика чиселОба значения числовые
-A, +A, -a, +aУнарный знакМатрица или число
(выражение)Изменение порядка вычисленийКорректное внутреннее выражение

Унарный знак имеет самый высокий приоритет. Умножение выполняется раньше сложения и вычитания. Операции одного приоритета выполняются слева направо. Например, A + B * C означает A + (B * C).

Число и матрица в одной бинарной операции не допускаются. Например, 2 * A — ошибка. Операция * между матрицами всегда означает матричное умножение. Поэлементное умножение, деление, степень, индексирование, изменение отдельных элементов, сравнения, циклы, условия и пользовательские функции не поддерживаются.

Встроенные функции

Каждая функция принимает ровно один матричный аргумент. Аргументом может быть выражение.

ФункцияРезультатДополнительные условия
transpose(A)Транспонированная матрицаЛюбая допустимая матрица
det(A)Число — определительКвадратная матрица
inverse(A)Обратная матрицаКвадратная и численно невырожденная матрица
rank(A)Целое неотрицательное число — численный рангЛюбая допустимая матрица

Примеры: transpose(A * B), det(A + B), rank([[1, 2], [2, 4]]). Вызовы det(3), rank(), inverse(A, B) и неизвестные имена функций отклоняются.

Вывод результатов

print(A);
print(det(A));
print((n + 1) * 2);

print принимает одно выражение и печатает его значение после запуска созданной программы Python. Для вывода нескольких значений пишите несколько команд. Строковые подписи и несколько аргументов в одной команде не поддерживаются. Матрицы печатаются по строкам в формате NumPy с точностью вывода до 10 цифр после десятичной точки и автоматической экспоненциальной записью; расчёты используют float64. Численный ранг печатается как целое число.

Комментарии

// До конца строки
# До конца строки
/* Комментарий
   в нескольких строках */

Текст комментариев может содержать кириллицу. Вложенные комментарии /* ... */ не поддерживаются. Незакрытый комментарий вызывает ошибку.

Ошибки и численная точность

Сообщения об ошибках исходного текста имеют формат файл:строка:столбец: причина. Строки и столбцы нумеруются с единицы; табуляция считается одним символом. Сообщается первая обнаруженная ошибка. Исправьте её и повторите трансляцию. Например:

input.mat:3:14: семантическая ошибка: невозможно умножить матрицы размеров 2x3 и 2x2: число столбцов первой матрицы должно совпадать с числом строк второй

Размеры матриц проверяются до создания программы. Вырожденность проверяется во время её выполнения. Для численного ранга применяется сингулярное разложение: значимыми считаются сингулярные числа, для которых s / s_max > max(m, n) * eps, где eps — машинная точность float64, примерно 2.22e-16. У нулевой матрицы ранг равен нулю. Если ранг квадратной матрицы меньше её размера, обращение запрещается. Поэтому почти вырожденная матрица также может быть отклонена: это учитывает погрешность вычислений. Подход соответствует стандартному порогу NumPy matrix_rank.

При ошибке вычисления выводится причина и позиция исходной команды или функции; необработанный стек Python не показывается. Программа завершается с кодом 1. Уже напечатанные ранее результаты сохраняются. При отсутствии NumPy выводится инструкция установки и код 3. Переполнение и нечисловые результаты вычислений диагностируются. Очень малые результаты операций могут округляться до нуля из-за ограничений float64; символьная и произвольная точность не предусмотрены.

Ограничения реализации: входной файл не более 16 МиБ, не более 100000 токенов и глубина дерева выражения не более 512. Пробелы и комментарии в количество токенов не входят. Глубина увеличивается и при длинной последовательности операций одного приоритета.

Готовый пример

В examples/input.mat находится пример со всеми операциями из задания. Его результат трансляции — examples/output.py, вывод вычислений — examples/stdout.txt. Нормальный пример не пишет в поток ошибок, поэтому соответствующие файлы .stderr.txt пусты. Файлы size_error.* показывают ошибку размеров, а singular_error.* — диагностику вырожденной матрицы при выполнении.
