# Справка пользователя Matrix Translator

Версия 1.0.0. Matrix Translator читает программу матричных вычислений из текстового файла и создаёт файл `.py`. Чтобы получить ответ, запустите созданный файл в Python.

## Установка и запуск

Распакуйте весь архив и откройте терминал в папке проекта. Готовый транслятор находится в `bin/`. Для выполнения полученных программ понадобится Python 3.11 или новее и NumPy 2.3.5. Приведённые команды устанавливают NumPy в локальное окружение `.venv`.

### Windows 10 и 11 x64

Установите Python x64 с доступной командой `python`. Выполните команды в PowerShell.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\bin\translator.exe examples/input.txt -o demo_output.py
.\.venv\Scripts\python.exe demo_output.py
```

Чтобы увидеть результаты с подписями, откройте `run_example.bat`.

### Linux x86_64

Установите Python с модулем `venv`, например пакет `python3-venv` в Debian или Ubuntu.

```bash
chmod +x bin/translator
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./bin/translator examples/input.txt -o demo_output.py
.venv/bin/python demo_output.py
```

## Своя программа

1. Создайте файл `input.txt` в кодировке UTF-8 и запишите в него программу.
2. На Windows запустите `.\bin\translator.exe input.txt -o output.py`. На Linux выполните `./bin/translator input.txt -o output.py`.
3. Запустите `output.py` тем же Python, которым запускали пример.

Ключ `-o` обязателен. Пути с пробелами заключайте в двойные кавычки. Каталог для `output.py` должен существовать. Входной и выходной файлы должны быть разными. При успешной трансляции выходной файл заменяется. Если транслятор обнаружил ошибку, он оставляет существующий файл как есть.

Добавьте `--help`, чтобы получить краткую справку, или `--version`, чтобы узнать версию. Каждый из этих ключей используйте отдельно от остальных аргументов. При ошибке запуска транслятор покажет справку.

## Формат входного файла

Проект использует собственный язык матричных вычислений. Сохраните файл в UTF-8 с расширением `.txt`. Допустимы также другие расширения. Файл может начинаться с UTF-8 BOM. Поддерживаются окончания строк LF и CRLF. Команды выполняются сверху вниз. Заканчивайте каждую команду знаком `;`. Соседние слова разделяйте пробелом, табуляцией или переносом строки. Пустой файл или файл только с комментариями даёт программу без вывода.

### Переменные и числа

```text
matrix A = [[1, 2], [3, 4]];
number n = 2.5;
A = transpose(A);
n = n + 1;
print(A);
print(n);
```

Объявите переменную через `matrix` для матрицы или `number` для числа и сразу задайте начальное значение. После объявления присваивайте новое значение того же типа через `=`. Размер матрицы может измениться при присваивании. Используйте имя только после объявления и объявляйте его один раз.

Используйте в имени латинские буквы, цифры и `_`. Начинайте имя с буквы или `_`. Написания `A` и `a` обозначают разные переменные. Слова `matrix`, `number`, `print`, `transpose`, `det`, `inverse` и `rank` зарезервированы. Кириллица допустима в комментариях и путях.

Числа записывайте с десятичной точкой. Допустимы, например, `12`, `-3`, `+4`, `2.5`, `.5`, `1.`, `-2.5e-3` и `3E+2`. Ведущие нули допустимы. Двоичные и шестнадцатеричные записи, подчёркивания в числах, `NaN`, `Inf` и комплексные числа не поддерживаются. Литералы должны помещаться в диапазон `float64`. Записи вроде `1e309` и ненулевые числа, округляющиеся до нуля, отклоняются.

### Матрицы

Запишите строки матрицы в квадратных скобках, разделив их запятыми. Например, `[[1, -2, 3.5], [4, 5, 6]]` задаёт матрицу из двух строк и трёх столбцов. У матрицы должна быть хотя бы одна строка. Во всех строках должно быть одинаковое ненулевое количество элементов. Элементом может быть только число с одним необязательным знаком `+` или `-`.

Формы `[]`, `[[]]`, `[1, 2]`, `[[1, 2], [3]]`, `[[n]]`, `[[1+2]]` и `[[[1]]]` вызовут ошибку. Завершающие запятые после элемента или строки не допускаются.

### Операции

- `A + B` и `A - B` складывают и вычитают матрицы одинаковых размеров поэлементно.
- `A * B` умножает матрицы. Проверьте, что число столбцов в `A` равно числу строк в `B`.
- Для двух чисел доступны `+`, `-` и `*`. Для одного числа или матрицы допустим знак перед выражением, например `-A` или `+n`.
- `transpose(A)` меняет строки и столбцы местами. `rank(A)` возвращает численный ранг в виде целого числа. Обе функции принимают в том числе прямоугольные матрицы.
- `det(A)` возвращает определитель квадратной матрицы. `inverse(A)` вычисляет обратную квадратную матрицу, если она численно обратима.

Каждая из четырёх функций принимает одно матричное выражение. Например, `transpose(A * B)` корректно при совместимых размерах. Число в `det(3)`, пустой вызов `rank()` и два аргумента в `inverse(A, B)` вызывают ошибки.

Сначала вычисляются унарные знаки, затем умножение, затем сложение и вычитание. Операции одного приоритета выполняются слева направо. Используйте скобки, если нужно сначала посчитать сумму, например `(A + B) * C`.

Смешивать число и матрицу в бинарной операции нельзя, поэтому `2 * A` вызовет ошибку. Поэлементное умножение, деление, степени, обращение к отдельным элементам, ввод с клавиатуры, строки, сравнения, условия, циклы и свои функции не поддерживаются.

### Вывод и комментарии

Напишите `print(выражение);`, чтобы вывести одно число или матрицу. Для нескольких значений пишите отдельные команды `print`. Подписи в кавычках внутри `print` и несколько аргументов не поддерживаются. Матрицы выводятся по строкам, как в NumPy.

Текст после `//` или `#` до конца строки считается комментарием. Для нескольких строк заключите текст в `/* ... */`. Вложенные и незакрытые многострочные комментарии не допускаются.

## Если возникла ошибка

Транслятор указывает имя файла, строку, столбец и причину ошибки в исходной программе. Нумерация начинается с 1. Исправьте первое указанное место и повторите трансляцию.

По коду завершения можно определить причину остановки транслятора.

- `0` при успешном переводе, выводе справки или версии.
- `1` при ошибке в программе, в том числе при несовместимых размерах.
- `2` при неверных аргументах запуска.
- `3` при ошибке чтения или записи, нехватке памяти или входном файле больше 16 МиБ.

Если ошибка возникла при запуске файла `.py`, прочитайте сообщение Python-программы. Ошибка вычисления, например обращение вырожденной матрицы или переполнение, даёт код `1` и позицию выражения во входном файле. При отсутствии NumPy программа даёт код `3`. В этом случае повторите установку зависимостей и запустите файл из `.venv`.

Вычисления используют приближённые числа `float64`, поэтому определитель может печататься как `-2.0000000000000004` вместо `-2`. Численный ранг зависит от точности вычислений. Обращение матрицы отклоняется, если при этой точности ранг меньше её размера.

Транслятор обрабатывает файлы размером до 16 МиБ и до 100 000 токенов. Предельная глубина выражения составляет 512 узлов. При превышении предела уменьшите размер входа или разбейте слишком длинное выражение на несколько присваиваний.
