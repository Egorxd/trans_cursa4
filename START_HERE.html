Matrix Translator 1.0.0

Комплект курсовой работы по трансляции языка матричных вычислений в Python.

Документация

Справка пользователя объясняет установку, запуск и все допустимые конструкции языка.

Пояснительная записка описывает грамматику, архитектуру, семантику, генерацию кода и тестирование.

Инструкция по сборке содержит необходимые инструменты и команды для Windows, Linux и Docker.

Запуск примера

Установите Python 3.11 или новее x64 с добавлением команды python в PATH. В Windows откройте run_example.bat: при первом запуске он создаст окружение и установит NumPy. Демонстрация показывает исходные матрицы и пояснения перед каждым результатом. Для первой установки зависимостей нужен интернет.

Для запуска из PowerShell выполните в папке проекта:

powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\bin\translator.exe examples/input.txt -o examples/output.py
.\.venv\Scripts\python.exe examples/output.py
